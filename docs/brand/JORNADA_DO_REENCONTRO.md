## O Manifesto do Reencontro — texto completo

Há momentos que quase todo mundo já viveu.

Você coloca a mão no bolso.
Olha para a mesa.
Volta alguns passos.
Procura novamente.
E então percebe.
Algo importante ficou para trás.

O silêncio que vem depois é diferente.
Você não sabe onde procurar.
Não sabe se alguém encontrou.
Não sabe se ainda existe uma chance.

Em algum outro lugar, alguém pode estar vivendo um momento diferente.
Encontra uma carteira.
Um celular.
Uma mochila.
Um documento.
Olha ao redor.
Não vê o dono.
Quer fazer a coisa certa.
Mas não sabe como.

Existe ainda uma terceira história.
Alguém está prestes a comprar um objeto usado.
Antes de confiar no vendedor, procura um número de série.
Um IMEI.
Um QR Code.
Porque ninguém quer descobrir tarde demais que comprou algo que nunca deveria ter sido vendido.

Essas três pessoas nunca se conheceram.
Mas elas dependem umas das outras.

Durante muito tempo, não existiu uma maneira simples, segura e confiável de conectá-las.

Nós acreditamos que isso pode mudar.

Acreditamos que perder um objeto não deveria significar perder as chances de reencontrá-lo.
Acreditamos que fazer a coisa certa deveria ser simples.
Acreditamos que tecnologia não serve apenas para localizar coisas.
Serve para aproximar pessoas.

Foi por isso que nasceu o Backfindr.

Não apenas para registrar objetos.
Mas para criar uma rede de colaboração onde cada nova informação aumenta as oportunidades de reencontro.

Enquanto você continua com a sua vida, o sistema continua trabalhando.
Comparando registros.
Recebendo novos achados.
Protegendo patrimônios.
Conectando histórias.

Porque confiança não nasce quando alguém promete ajudar.
Ela nasce quando existe um sistema que continua trabalhando, mesmo quando ninguém está olhando.

Se você perdeu algo, ainda pode haver uma oportunidade.
Se você encontrou algo, existe uma maneira segura de ajudar.
Se você quer proteger o que é importante, o melhor momento é antes da perda acontecer.

O Backfindr existe para conectar essas três histórias.
Porque todo reencontro começa quando alguém decide colaborar.

---

## As três frases que o visitante deve lembrar

1. *Perder um objeto não significa perder as chances de reencontrá-lo.*
2. *O Backfindr continua trabalhando mesmo quando você não está olhando.*
3. *Todo reencontro começa quando alguém decide colaborar.*
